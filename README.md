# School Management System

A full stack MERN School Management System project.

## Features

- Dashboard
- Add Student
- Student List
- Student Details
- Edit Student
- Delete Student
- Search & Filter
- Responsive Design

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB Atlas

## Run Frontend

cd client
npm install
npm run dev

## Run Backend

cd server
npm install
npm start
