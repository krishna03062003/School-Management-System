# School Management System

A full stack MERN School Management System project built using React.js, Node.js, Express.js, and MongoDB Atlas.

---

## Features

- Dashboard
- Add Student
- Edit Student
- Delete Student
- Student List
- Student Details
- Search & Filter Students
- Responsive UI Design
- CRUD Operations
- API Integration
- Validation & Error Handling

---

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB Atlas
